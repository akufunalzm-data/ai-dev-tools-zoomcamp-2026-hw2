# TableFlow

Restaurant waitlist management application built for DataTalks.Club AI Dev Tools Zoomcamp 2026 Homework 2.

## Overview

TableFlow helps restaurant staff manage customer waitlists, assign tables, and send simulated SMS notifications when tables become available.

## Features

- Add customers to a waitlist
- View and manage the waitlist
- Assign tables with recommendations
- Simulate SMS notifications
- Track customer status
